Quick start

Install the package and run your first routed choice / score / noul decision in about twenty lines.

Install

pip install "laya>=0.3.6" scikit-learn   # scikit-learn only needed for long-context retrieval
export HF_TOKEN=...                        # only if a checkpoint is gated

20-line example

from laya import Router

r = Router()  # lazy: checkpoints download on first use
state = {"message": "I was charged twice for order #4821",
         "history": ["agent asked for order id", "user provided it"]}

res = r.predict(state, {
    "intent": {"type": "choice", "instructions": "What does the user want?",
               "criteria": {"refund": "wants money back",
                            "status": "asks where the order is",
                            "cancel": "wants to stop the order"}},
    "urgency": {"type": "score", "instructions": "How urgent is this?",
                "criteria": ["1", "2", "3", "4", "5"]},
    "fraud": {"type": "noul", "instructions": "This looks like fraud."},
})

print(res["answers"]["intent"]["probabilities"])
print(res["answers"]["urgency"]["probabilities"], res["answers"]["fraud"]["noul"])
print(res["routing"])  # which checkpoint answered, and why

What you get back

Each answer carries probabilities over its options (or a noul score in [0, 1]), plus calibrated confidence. The extra routing key records the checkpoint decision. All three questions above are answered in one forward pass.
