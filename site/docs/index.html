Introduction

Laya-Plus is an open, self-hosted System-1 decision model: state plus typed questions in, calibrated choice / score / noul probabilities out. No text generation.

What it is

Laya-Plus maps state + typed questions -> calibrated decision. You hand it a state (a string, a JSON dict, or conversation turns) and a dict of typed questions (choice, score, noul). It returns probabilities and calibrated confidence for every question — in a single forward pass, with no text generation.

Decisions, not chat: there is no autoregressive decoding loop. Latency is one encoder pass per batch (~32ms single-pass behaviour for native-window inputs).

System One

The runtime entry point is Agent.system_one(state, questions). Every question is rendered against the same state, marker positions locate each option, and one encoder pass scores all of them in parallel. See Primitives for the three question types and Python API for signatures.

Targets

We track the Jev 1.13.0 targets: typed-decisions 0.727, AG News 0.910, Emotion 0.480, Banking77 0.870, ECE 0.246. Measured numbers are still TBD — see Benchmarks + targets. We never fabricate scores.
