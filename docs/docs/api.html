Python API

Exact signatures from the real modules: laya.Router, laya.Agent, src/laya_longctx.py, laya-train/hier.py, laya.shortlist, laya-train/eval.py.

Router — laya.Router

Router(models=None, device=None, token=None, max_loaded=1,
       default="english", auto_task_detection=False,
       standalone_repos=False, preload=False)
route(state, questions=None, model=None, task=None, lang=None) -> RouteDecision
predict(state, questions, model=None, task=None, lang=None) -> dict  # + ["routing"]
system_one = predict
load(name) -> Agent
attach(name, agent)
preload(names=None)
unload(name=None)
loaded() -> List[str]

RouteDecision is a dict with model, repo, reason, detection, workflow. models maps names to (repo, subfolder); inference runs outside the lifecycle lock so concurrent predictions share a checkpoint.

Agent — laya.Agent

Agent(model_id_or_path="convaiinnovations/laya", device=None,
      token=None, subfolder=None)
system_one(state, questions) -> {"answers": {qid: {...}}, ...}
load(model_id_or_path="convaiinnovations/laya", device=None, ...)  # module fn

state: str | dict | list. Answers carry probabilities (choice/score) or noul (float in [0, 1]), plus calibrated confidence. Window: max_len 512, head_max_len 192 from rl_agent_config.json.

LongContextRouter — src/laya_longctx.py

LongContextRouter(router=None, **router_kwargs)
predict(state, questions, top_k=3, chunk_words=120, overlap=20, **kw) -> dict

Fast path: inputs around 900 tokens or fewer go straight to router.predict with longctx={"retrieved": False, "chunks": 1}. Longer inputs are reduced by select_state and annotated with chunks / kept indices / scores.

Eval harness — laya-train/eval.py

python laya-train/eval.py <ckpt_dir> [--suite all|td|ag|emo|bank77]
# ckpt_dir: model.safetensors + encoder/ + tokenizer/ + rl_agent_config.json

Per suite: accuracy + ECE, plus latency P50 (1-question and 10-question batched). Targets live in the JEV dict: td 0.727, ag 0.910, emo 0.480, ece 0.246, lat1 256.0, lat10 1500.0, bank77 0.870. Helpers ece(probs, labels, n_bins=10) and run_choice(agent, texts, crit, instructions, batch=16) are importable.
