Patterns

Three production patterns — gate on confidence, coarse-to-fine over huge label sets, retrieve before you decide — plus where they apply.

Confidence-gated routing

Because probabilities are calibrated, low confidence is actionable: answer directly when the top probability clears your threshold, otherwise escalate — ask a follow-up, route to a human, or collect more state.

ans = res["answers"]["intent"]["probabilities"]
top = max(ans.values())
if top < 0.6:
    escalate(state)   # clarify, human review, richer state
else:
    act_on(max(ans, key=ans.get))

Shortlist coarse-to-fine

For label sets far beyond the head budget (Banking77: 77 intents), rank options with cheap embeddings, then run the decision head over the top-k. This is the eval’s Banking77 method (shortlist k=20, target 0.870).

from laya.shortlist import shortlist_choice, predict_shortlist
top20 = shortlist_choice(state, criteria, embed_fn, k=20)
res = predict_shortlist(agent, state, questions, embed_fn, k=20)

embed_fn maps [query, *options] to vectors in one call; ties keep the earlier label; when k covers all labels everything passes through untouched.

Retrieve-then-decide

For states beyond the native window, chunk + TF-IDF-rank against the question text and decide over the top-k chunks — see Long context. One retrieval pass plus one decision pass; no chunk is ever generated from, only decided over.
